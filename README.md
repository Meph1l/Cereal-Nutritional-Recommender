# Cereal-Nutritional-Recommender

# Setting up project
1. cd into ./backend
2. run 'npm install'
3. cd into ./frontend
4. run 'npm install @tailwindcss/vite'
5. create 2 terminals
6. in terminal one, CD into ./frontend 
7. run 'npm run dev'
8. in terminal two, CD into ./backend
9. run 'node server.js'
